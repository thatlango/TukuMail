# Third-party foundations

TukuMail is not a fork of a commercial mail-control product.

The server-side engine boundary is designed to use Apache-2.0 licensed Apache James protocol components for SMTP/IMAP interoperability. Apache notices and license obligations must be preserved in distributions that include those components.

The Android application is structured so the mature Apache-2.0 licensed Thunderbird for Android/K-9 codebase can be brought in as an upstream subtree during the client-hardening phase. Tuku trademarks, package identifiers, OAuth credentials and assets must remain independent.
