# TukuMail Desktop

The desktop client is a distinct delivery target, not a browser tab packaged without a security model.

The next tranche will choose the desktop runtime after the web/message contracts stabilise. Requirements are:
- OS credential-store integration;
- encrypted local message/cache storage;
- system notifications and mailto handling;
- safe attachment download/opening;
- automatic signed updates;
- the same Tuku identity and mailbox contracts as web/Android.

No desktop runtime is claimed as implemented by this foundation commit.
